# NABZ Production Candidate

## Selected direction

The layered woven landscape storefront was selected as the production direction. The numbered study language has been removed from the customer-facing experience.

## Shopify preview

- Standard preview: https://j1hsp8-gg.myshopify.com/?preview_theme_id=154346815682
- Full loader replay: https://j1hsp8-gg.myshopify.com/?preview_theme_id=154346815682&loader=1

The Shopify theme is named `NABZ Production Candidate` and remains unpublished.

## Brand mark

The supplied embroidered NABZ artwork is used in three places:

- Navigation
- Loading sequence
- Closing brand statement

Transparent margins were trimmed for correct storefront sizing. The artwork was not redrawn.

## Loading sequence

The first visit opens with a dark textile field. A glowing needle stitches the copper pulse path while the embroidered wordmark is revealed in sync. The screen then separates along a glowing center seam to reveal the storefront.

Repeat visits use a shorter sequence. Reduced-motion preferences receive an immediate, accessible reveal. Add `loader=1` to the preview URL to replay the complete sequence.

## Production changes

- Removed Option 10, study, prototype and laboratory labels from the visible storefront
- Replaced the comparison navigation with Surface, Fit, Collection and Bag
- Added live cart count
- Reduced launch storytelling to Self Contour and Air Cable
- Preserved the selected textile background and palette
- Added keyboard focus states and responsive production layouts
- Retained real Standard and Extended fit imagery
- Added a loader safety timeout and storage fallback
- Avoided long em dash and en dash characters in permanent site copy
