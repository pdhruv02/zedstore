# NABZ Real Assets v2

This build uses the supplied production images only. No generated garment, SVG shirt silhouette, fallback photography, or CSS-deformed fit visual is permitted.

## Theme

- Shopify theme: `NABZ Real Assets v2`
- Homepage section: `sections/nabz-real-assets-v2.liquid`
- Fit imagery switches between six supplied transparent WebP assets.
- Desktop and mobile hero, closing, and editorial crops are distinct supplied files.
