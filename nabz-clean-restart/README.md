# NABZ clean restart

This is the new homepage baseline.

- Native browser scrolling only
- No canvas, sprite sheets, scroll locking, or frame animation
- Continuous dark embroidered textile background
- Supplied NABZ photography and real fit renders only
- Independent Shopify sections for hero, story, surface, fit, closing, and catalog
- Existing Shopify catalog and commerce templates remain intact

The purpose of this baseline is stability. Each homepage section can now be redesigned independently.
